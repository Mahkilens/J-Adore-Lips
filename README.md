# J'Adore Lips Website 💄

A modern, high-converting e-commerce landing page built for a beauty brand client, designed to showcase and sell a premium lip plumper product.

---

## 🚀 Project Overview

This project is a custom-built website for **J'Adore Lips Cosmetics**, focused on creating a clean, luxury user experience that highlights the product and encourages conversions.

The goal is to deliver a professional, visually appealing, and mobile-friendly landing page that reflects a high-end beauty brand.

---

## ✨ Features

- Responsive landing page design
- Modern hero section with product focus
- Clean and minimal luxury UI
- Product showcase section
- Contact form for customer inquiries
- FAQ page for common questions
- Navigation with mobile menu support
- Ready for Shopify Buy Button integration

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
